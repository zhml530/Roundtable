Roundtable is a desktop-only, local-first app. Agent CLIs run on your machine, application state lives under `~/.Roundtable`, and the UI talks to orchestration through typed Electron IPC rather than a local HTTP server.

## Typical local setup

1. Run Roundtable on your personal macOS, Windows, or Ubuntu computer.
2. Install and authenticate the agent CLIs you want to use.
3. Add optional third-party keys only for the services you need.
4. Launch the Electron desktop app.

## What is still third party

Self-hosting Roundtable does not self-host every optional provider:

- Agent providers authenticate and bill through their own CLI or API.
- Box owns managed cloud computers.
- ElevenLabs synthesizes speech when voice is enabled.

These services are optional. Local chat through a locally installed agent CLI does not require them.

## Run during development

```bash
pnpm install --frozen-lockfile
pnpm dev:desktop
```

Electron starts orchestration in a utility process and connects it to the renderer through the preload bridge. There is no supported headless HTTP-server mode.
